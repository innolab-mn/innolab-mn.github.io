Сургалтын зорилго

  • Blender–ийн интерфэйс

  • 3D моделингийн үндсээс эхлэн нарийн обьект хийх арга барил сурах

  • Материал, текстур болон гэрэлтүүлэг ашиглан бодит мэт дүрслэл гаргах

  • Animation хийх

  • Eevee болон Cycles рендэрийн тохиргоогоор өндөр чанартай зураг/видео гаргах

🛠 Сургалтын Хөтөлбөр

1. Blender Орчин ба Үндсэн Хэрэглүүрүүд

  • Viewport, Toolbar, Properties Panel–ын танилцуулга

  • Navigation (камераар эргэх, ойртуулах, шилжих)

  • Object ба Edit Mode–ын ялгаа

2. Моделинг (Modeling)

  • Mesh Modeling

    • Primitive обьектууд (Cube, Sphere, Cylinder, Plane гэх мэт)

    • Extrude, Inset, Loop Cut, Bevel, Mirror зэрэг командууд

  • Modifiers ашиглах

    • Subdivision Surface → жигд дугуй хэлбэр гаргах

    • Mirror Modifier → симметрик модел хийх

    • Boolean → нүх гаргах, огтлох, нэгтгэх

  • Hard Surface vs Organic Modeling

    • hart surface (багаж, машин, тавилга)

    • organic modeling (хүн, амьтан, байгалийн обьект)

3. Материал ба Текстур (Materials & Shading)

  • Shader Editor ашиглах

  • Principled BSDF Shader → металл, мод, шил, хуванцар зэрэг олон төрлийн материал үүсгэх

  • UV Mapping → 2D зураг (texture)–ийг 3D обьект дээр зөв байрлуулах

  • Procedural Materials → зураг ашиглахгүйгээр материал үүсгэх (wood, marble, noise гэх мэт)

  • Node системийн ойлголт

4. Гэрэлтүүлэг (Lighting)

  • Point, Spot, Area, Sun гэрлийн төрлүүд

  • HDRI environment light ашиглан бодит гэрэлтүүлэг үүсгэх

  • 3-point lighting setup (Key, Fill, Rim light)

5. Рендер (Rendering)

  • Eevee Render Engine

    • Түргэн, real-time рендер (preview, animation test)

  • Cycles Render Engine

    • Ray-tracing суурьтай, илүү бодит дүрслэл

  • Render Settings

    • Samples, Denoising, Resolution, Output Format

  • Камерын тохиргоо

    • Depth of Field, Focal Length

6. Практик Даалгавар

  • Тоног төхөөрөмж, хүүхэлдэйн модел хийх

  • Материал оноож, текстур оруулах

  • HDRI ашиглан гэрэлтүүлж, бодит зураг гаргах

  • Эцэст нь: жижиг интерьер/экстерьер сцена рендэрлэх

🎯 Сургалтын Үр Дүн

  • Blender–ийн моделинг хэрэгслүүдийг ашиглан ямар ч төрлийн 3D загвар бүтээж чадна

  • Материал, текстур, гэрэлтүүлгийн мэдлэгтэй болж, бодит дүрслэл хийх чадвартай болно

  • Cycles болон Eevee рендэрээр өндөр чанартай зураг, анимаци гаргаж чадна

  • 3D хэвлэх, тоглоомын ассет, уран бүтээл, сурталчилгаанд ашиглах боломжтой болно
